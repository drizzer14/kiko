# Kiko

> 🇺🇦 Українською · 🇬🇧 [English](./README.en.md)

**Kiko (Кіко)** — це приватний застосунок для особистих фінансів на iPhone, що
працює локально. Він зводить ваш банк, готівку та крипту в один огляд чистого
капіталу — без сервера, без облікового запису та без відстеження.

## Можливості

- **Один чистий капітал, багато джерел.** Відстежуйте рахунки, активи та
  транзакції в банках, готівці та крипті в одному огляді.
- **Синхронізація з Monobank.** Отримуйте баланс і виписки Monobank за вашим
  особистим токеном API.
- **Синхронізація з Binance.** Читайте баланси спотового рахунку Binance за
  ключем API лише для читання (запити підписуються HMAC на пристрої).
- **Bitcoin ончейн.** Додайте адресу Bitcoin, і Kiko прочитає її баланс із
  публічного блок-експлорера (Blockstream).
- **Мультивалютність.** Тримайте UAH, USD, EUR та BTC. Kiko переводить усе у
  вашу базову валюту за курсами Національного банку України та CoinGecko.
- **Статистика.** Лінія чистого капіталу в часі, кільцева діаграма внеску
  рахунків, а також кільцева діаграма категорій із трендом витрат.
- **Категорії.** Упорядковуйте витрати за кольоровими категоріями.
- **Дві мови.** Повна локалізація українською та англійською.

## Приватність і безпека

Kiko працює локально та поважає вашу приватність:

- **Без сервера, без облікового запису, без відстеження.** Застосунок не має
  бекенду, яким керуємо ми, і не містить аналітики, реклами чи звітування про
  збої.
- **Шифрування на пристрої.** База даних зашифрована за допомогою AES-256
  (SQLCipher). Облікові дані API зберігаються в iOS Keychain.
- **Закріплений TLS.** З'єднання, що містять облікові дані, використовують TLS
  із закріпленням сертифікатів.
- **Блокування застосунку.** Необовʼязкове блокування за Face ID або
  кодом-паролем пристрою.

Повна політика: [Політика конфіденційності](./docs/privacy-policy.md) ·
онлайн за адресою <https://drizzer14.github.io/kiko/>

## Платформа

- Лише iPhone, iOS 26 або новіша (використовує дизайн Apple Liquid Glass).
- Темна тема.

## Технології

- **React Native** 0.87 + **TypeScript**, React 19
- **op-sqlite** + **Drizzle ORM** — зашифрована локальна база даних
- **react-native-unistyles** — дизайн-система та теми
- **React Navigation** з нативною нижньою панеллю вкладок
- **react-native-reanimated** + **react-native-sortables** — жести та
  перетягування
- **react-native-svg** — діаграми
- **react-native-keychain** — безпечне сховище облікових даних
- **@noble/hashes** — підписування запитів Binance

## Початок роботи (розробка)

Вам потрібне робоче середовище React Native для iOS: Xcode, Node та Ruby
bundler.

```sh
# 1. Встановіть залежності JS (postinstall також генерує .env з .env.example)
npm install

# 2. Встановіть нативні поди iOS
bundle install
(cd ios && bundle exec pod install)

# 3. Запустіть на симуляторі
npm run ios

# Або розгорніть на під'єднаному iPhone
npm run deploy:device
```

Конфігурація зберігається в `.env` (публічні, несекретні значення, що
генеруються автоматично з `.env.example`). Секрети там ніколи не зберігаються —
вони йдуть в iOS Keychain.

## Гарантія якості

Kiko має суворий набір перевірок якості. Кожна перевірка виконується через
обгортку в `scripts/checks/`:

```sh
npm run check:all    # lint, dup, knip, deps, security, rules, plist, secrets, overrides, typecheck
npm run check:deep   # мутаційне тестування, а потім сканування відомих CVE
npm test             # модульні тести Jest
```

Повний опис набору перевірок дивіться у [`CLAUDE.md`](./CLAUDE.md).
